# 国内源码交易平台 - 直接上架卖

不用等客户来找你，直接去有客户的地方摆摊。

## 1. 闲鱼（最推荐，最容易出单）

打开 https://2.taobao.com → 发布闲置
- 标题：AI写作平台源码 FastAPI开发 带支付 可商用
- 文案：用 marketing/promotion/xianyu-listing.md
- 定价：¥299
- 分类选：数码产品 → 软件/编程
- 上传 3 张截图

闲鱼有搜索流量，标题写得好会有人搜到。

## 2. 掘金（开发者社区）

打开 https://juejin.cn
- 写一篇文章"用FastAPI开发了一个AI写作平台，分享一下架构"
- 文末放 Gumroad 链接
- 掘金对技术文章有推荐流量

## 3. 开源中国（OSChina）

打开 https://oschina.net
- 在"开源软件"分类提交你的项目
- 描述里写清楚功能
- 链接到 GitHub 仓库（GitHub Pages 展示页）

## 4. V2EX

打开 https://v2ex.com
- 在"分享创造"节点发帖
- 用 marketing/promotion/v2ex-post.md
- V2EX 的开发者用户质量高

## 5. 技术博客投稿

去以下平台搜索"AI写作"、"源码出售"相关的文章，在评论区留言：
- CSDN
-  SegmentFault（思否）
- 知乎相关回答

## 6. 微信技术群

搜索"Python开发群"、"AI交流群"、"独立开发者群"
进群后发 marketing/promotion/wechat-messages.md 里的版本B
