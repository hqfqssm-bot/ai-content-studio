AI Content Studio is a complete, production-ready SaaS platform for AI-powered content generation. Built with FastAPI and a clean vanilla JS frontend, it includes everything you need to launch your own AI writing tool business.

### Why Buy This?

Instead of spending weeks building auth, payments, and a content generation system from scratch, get a battle-tested platform that's ready to deploy. Just add your OpenAI and Stripe API keys, and you're in business.

### Core Features

**Authentication & User Management**
- JWT-based register/login system with bcrypt password hashing
- User profiles with credit balances and Pro status
- Secure token-based API authentication

**AI Content Generation (6 Types)**
- Blog Posts - Well-structured articles with markdown formatting
- Social Media - Platform-optimized posts with hashtags
- Advertisements - Conversion-focused copy with CTAs
- Email Marketing - Professional emails with subject lines
- SEO Content - Meta titles, descriptions, and keyword-rich body
- Custom - Any content the user needs

**Monetization (Built-in)**
- Credit system: Free tier (5 credits) + Pro tier (100 credits/month)
- Full Stripe Checkout integration for subscription payments
- Stripe webhook handler for automatic Pro upgrades
- Configurable pricing ($19.99/month default)
- Demo mode works without an API key

**API & Integration**
- RESTful API with full documentation
- API key management for external integrations (Pro users)
- CORS-enabled for cross-origin requests
- All endpoints return JSON

**Deployment**
- Docker Compose with PostgreSQL + nginx reverse proxy
- One-command deploy: docker compose up -d
- Local development: uvicorn with hot reload
- Windows one-click startup script included
- Production nginx config included

**User Interface**
- Modern SaaS dashboard with credit overview
- Content type selector with visual cards
- Real-time content generation with markdown output
- Content history browser
- Settings page with API key management
- Mobile responsive design
- Dark sidebar navigation

### What's Included

- Full backend source code (FastAPI + SQLAlchemy)
- Complete frontend (Vanilla JS + CSS, single file)
- Docker Compose configuration
- nginx production config
- PostgreSQL database setup
- Stripe integration (checkout + webhook)
- API key management system
- JWT authentication system

### Requirements

- Python 3.10+
- OpenAI API key (for AI generation)
- Stripe account (optional, for payments)
- Docker (optional, for production deploy)

### Installation

1. pip install -r requirements.txt
2. Set your API keys in .env
3. uvicorn app.main:app --host 0.0.0.0 --port 8000
4. Open http://localhost:8000

Or with Docker:
docker compose up -d
